# Trivia Workout  
  
Repo: https://github.com/maceman1984/CSG-119-Spring-2026  

Trivia Workout is a trivia game I helped program for The Mad Cete which was recently picked up by the Milwaukee Wave team to use at sporting events.
Trivia workout is a game where you need to exercise to answer the questions correctly, the more points you have, the more balls you have to hold.
If you drop a ball you lose a point! Carry as many balls as you can while still being able to answer questions to win!
