# Lethal Company Mods  
When Lethal Company came out I was hooked. The game was so fun, but it felt like sucha missed opportunity that there were only 2 interiors at the time. 
I decided I wanted to just make an interior for the game inspired by Jared Pike and his artwork and so I got working.
This project took me several months to complete as the only documentation I had was a decompiled interior and a buggy unity instance, but it turned out beautifully with the help of many other coders and friends!
